# Project notes

The IHP SG13G2 PDK models and external EDA packages are not included. Obtain them from their original maintainers.

Simulation results depend on the model corner, bias, port definitions, frequency range, process stack and mesh settings. The repository contains simulation results rather than silicon measurements or a finished amplifier design. The supplementary scripts and layout examples are described in [analysis tools](reconstructed-tools.md).

The 500 GHz sweep limit is not a demonstrated operating bandwidth. See the internship report for the original plots and simulation conditions.
